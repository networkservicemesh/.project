# Security Policy

## Reporting Security Issues

The Network Service Mesh maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/networkservicemesh/api/security/advisories/new) form.

For more details, see the [Network Service Mesh security policy](https://github.com/networkservicemesh/api/blob/main/SECURITY.md).
